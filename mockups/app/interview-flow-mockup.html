Implementation Notes

Care History API

New endpoint: GET /api/sessions/history/:caregiverId/:recipientId

Returns: count of completed sessions, last 5 sessions with visit_log summary, moods, duration, date, service type, and interview count. One query with JOIN on visit_logs. Served to both family dashboard (Peter sees it) and caregiver dashboard (Cary sees it on open jobs).

Caregiver-Side Count

Dashboard API adds a batch query: SELECT care_recipient_id, COUNT(*) FROM care_sessions WHERE caregiver_id = ? AND status = 'completed' GROUP BY care_recipient_id. Each openJob card gets a previousVisitCount field. One extra query per dashboard load — not per job.

Database

New interviews table: id, session_id, requested_by_user_id, requested_by_role, interview_type (audio/video), status (pending→accepted→completed/declined/cancelled), call_duration_secs, created_at, accepted_at, completed_at.

Add interview_required BOOLEAN + interview_type VARCHAR to care_sessions.

Cancellation & Reminders

24-hour rule: Either party can cancel up to 24hr before. After that, session proceeds — interview optional.

Reminders: 48hr gentle push, 24hr cancel-deadline warning, 2hr final nudge. Session always proceeds as confirmed.

Chat & Twilio Video

Auto-create chat thread on interview accept. System message with session context. "Start Video Call" triggers Twilio room with 5-min server-side timeout. 30-second warning at 4:30. Audio fallback. Duration logged. No recording. Chat persists through session.

Repeat Caregiver Nudge

Peter's side (primary): Shows in Request Care modal and on interview request notifications. "Cary has cared for Betty 4 times · 1 previous interview." Expandable to show last 5 visits with mood, summary, cost. Tappable to open full VisitDetailModal.

Cary's side: Compact version on job cards in Find Work. "You've cared for Betty 4 times." Expandable to show date/mood dots for last 3-5 visits.
