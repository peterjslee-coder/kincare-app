Design Decisions

🌙 Built for Evening Caregiving

Caregivers often check the app late at night — after putting someone to bed, reviewing the day's notes, or prepping for tomorrow. The dark theme uses warm, desaturated backgrounds (#121218 with a slight purple-blue hue) to reduce eye strain without feeling cold or clinical.

🎨 Lifted Accent Colors

The brand teal shifts from #1b6b5a (dark, rich) to #4fd1b0 (luminous mint) so it pops on dark backgrounds while keeping the same warmth. Ocean blue and coral follow the same pattern — lighter and slightly desaturated to maintain contrast ratios above WCAG AA (4.5:1).

👁 Layered Elevation

Instead of drop shadows (invisible on dark backgrounds), depth is communicated through surface brightness: background (#121218) → surface (#1a1a24) → card (#1e1e2a) → elevated (#262636). Subtle 1px borders (#2a2a3a) reinforce card edges.

⚖ Role-Colored Tinting

Schedule blocks use dark tinted backgrounds (e.g., #1a2e28 for teal, #1a2438 for blue) rather than bright fills. This preserves the color-coding system you already have while keeping the overall surface dim. The left-border accent stays vivid for quick scanning.

🔌 Implementation: CSS Variables + Toggle

Since InPlace already uses CSS custom properties (--role-color, etc.), dark mode can be implemented by swapping a root-level data attribute (e.g., data-theme="dark") and overriding ~15 variables. Options: respect the OS setting via prefers-color-scheme, add a manual toggle in Settings, or offer "automatic" that switches at sunset based on the user's timezone.
