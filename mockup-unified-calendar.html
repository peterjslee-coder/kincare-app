Key Changes from Current Design:
① No heat map. Dots instead — one per session. Confirmed = solid teal. Pending = orange ring. In-progress = gold.
② Click any day → inline panel shows sessions + a "Book care on [date]" link. No separate modal hunt.
③ Empty days invite action with a prominent "Request Care for [date]" button instead of showing nothing.
④ Floating + button (bottom right corner) always visible for quick booking without picking a date first.
⑤ Cleaner cells — no colored backgrounds flooding the grid. Just the date + dots. Easier to scan.
⑥ Book button pre-fills the date so the Request Care modal opens with that day already selected.
